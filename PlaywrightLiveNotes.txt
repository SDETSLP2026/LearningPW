Load state with goto()
=======================
When to consider operation succeeded, defaults to load.

Events can be either:
'domcontentloaded' - consider operation to be finished when the DOMContentLoaded event is fired.
'load' - consider operation to be finished when the load event is fired.
'networkidle' - DISCOURAGED consider operation to be finished when there are no network connections for at least 500 ms. Don't use this method for testing, rely on web assertions to assess readiness instead.
'commit' - consider operation to be finished when network response is received and the document started loading.

OR

await page.waitForLoadState('load'):Promise<void> - Returns when the required load state has been reached.


Assertion
==========
- Assertion helps you to validate certain/current state of the application.
- For Assertion, Playwright supported 5sec autowait.
- First update test with test runner - import {test,expect} from "@playwright/test";

- Playwright support two type assertions
1.Hard assertion
------------------------
- If asertion applied and it is getting fail then
    hard assertion stops current test excution and after 5sec auto-wait (provided by Pw)
    you will see Error.
- By default PW supports hard assertion.

Syntax:
---------
expect(Locator/page)


2.Soft assertion
---------------------
- If asertion applied and it is getting fail then
    soft assertion never stops current test excution and after 5sec auto-wait (provided by Pw)
    you will see Error + all the execution steps
- For assertion, we use 'chai assertion library' with expect()

Syntax:
--------

What is WebElement?
-------------------------
Any UI element from page like inputbox,link,button,checkbox,radiobutton ...etc are called webelement.

How to automate webelement?
===============================
1. Identify webelement from application - In PW, to identify element based on css and xpath use locator()

AutoWaiting
====================
- Autowait in playwright is available for - Actionalble webelements & Assertion commands.
- Autowait in playwright is NOT available for - Navigation from one page to another page.
- Playwright support autowating for all actionable commands that is 30sec
- Playwright support autowating fo assertions that is 5sec




AutoWait for all the Actionalble commands in PW is 30sec
=======================================================
- Playwright performs a range of actionability checks on the elements before making actions to ensure these actions behave as expected. 
- It auto-waits for all the relevant checks to pass and only then performs the requested action.
- If the required checks do not pass within the given timeout (30sec), action fails with the TimeoutError.

For example, for locator.click(), Playwright will ensure that:

locator resolves to exactly one element
element is Visible
element is Stable, as in not animating or completed animation
element Receives Events, as in not obscured by other elements
element is Enabled

If element completed and pass theses checks within 30sec then playwright complete click action



Playwright identify webelement based on Locators

What is locator?
=====================
Locator is address of webelement from the webpage

Playwright support 3 strategies to locate the element
==========================================
1. Using cssSelector
2. Using xpath
3. Playwright Inbuilt locators
    page.getByRole() to locate by explicit and implicit accessibility attributes.
    page.getByText() to locate by text content.
    page.getByLabel() to locate a form control by associated label's text.
    page.getByPlaceholder() to locate an input by placeholder.
    page.getByAltText() to locate an element, usually image, by its text alternative.
    page.getByTitle() to locate an element by its title attribute.
    page.getByTestId() to locate an element based on its data-testid attribute (other attributes can be configured).



1.CssSelector
=====================

CSS: CSS stands for cascading style sheet , this is language used to provide styles to webelement

- CssSelector is locator to identify webelement we use it
- CssSelector identify webelement based on css properties of that element(like id,classname...etc)
- CssSelector is faster than xpath
- CssSelector can travel in only one direction parentTag ---> childTag (Reverse can't possible)
- CssSelector does not support any method it support special characters

In Playwright to identify element based on css and xpath use locator()

=================================================

Example: a.nav-link[href='sign-out.html']

CssSelectors with Substring Operators/Symbols
=============================================
 * => partial match: This is like contains() from Java OR includes() from JS
 ^ => startswith: match with prefix value
 $ => endsWith: match with suffix value

 1. * => partial match (contains/includes) 
 ==========================================
 Syntax:
 ========
 tagname[attribute *='partial value']

 Examples
 ========
 <input type="text" id="twotabsearchtextbox" value="">

 input[id *='searchtext'].......1 of 1


2. ^ startswith (prefix value)
===============================
Syntax
 ========
tagname[attribute ^='prefix value']

Example:
 ========
 <input type="text" id="twotabsearchtextbox" value="">

input[id ^='twotab'].........1 of 1 match

3. $ endsWith (suffix value)
============================
Syntax:
========
tagname[attribute $='suffix value']

Example:
 ========
 <input type="text" id="twotabsearchtextbox" value="">

input[id $='box'].........1 of 1 match
